# CS-340-Client-Server-Development
SNHU CS 340 portfolio project featuring a MongoDB database and an interactive Python Dash dashboard.

### How do you write programs that are maintainable, readable, and adaptable?

When I'm writing code, I try to keep everything organized and easy to follow, especially if I need to go back and make changes later. For Project One, I created a CRUD Python module that helped me connect to MongoDB and work with the data. When I started Project Two, I was able to use that same module for my dashboard instead of starting over. This saved me time and made it easier to focus on getting the dashboard to work correctly. I also learned how helpful it is to keep different parts of a program separate because it makes fixing problems and making changes a lot easier. I could see myself using this same approach in future projects, especially ones that involve working with databases.

### How do you approach a problem as a computer scientist?

When I'm working on a project, I find it easier to take things one step at a time instead of trying to do everything at once. For the Grazioso Salvare project, I first had to understand what the company was looking for and figure out how to make the dashboard work around those requirements. I started with the database connection and then worked on adding the filters, table, and charts. This project was a little different from my other assignments because I had to connect everything together and make sure each part worked correctly. I also ran into some errors along the way, so I had to go back, figure out what was causing them, and fix them. For future projects, I would take a similar approach by understanding what the client needs, planning how to organize the database, and testing my work as I go.

### What do computer scientists do, and why does it matter?

Computer scientists help solve problems by creating programs and finding ways to make things easier and more efficient. Their work is important because technology is used in so many different areas, and businesses rely on it to keep things running smoothly. For the Grazioso Salvare project, I created a dashboard that makes it easier for the company to look through animal shelter records and find animals that meet certain rescue requirements. Instead of having to go through all the records one by one, they can use the filters to narrow down their search. I think this is a good example of how computer science can help a company save time, stay organized, and make better decisions.
